# 🧠 NEUROCARDIA AI – Autonomous Heart & Brain Hospital Intelligence Platform

**NEUROCARDIA AI** is a next-generation hospital intelligence platform designed to bring artificial intelligence concepts, clinical decision support, hospital operations, medical imaging, and interactive 3D anatomical visualization into one unified interface.

The platform focuses on cardiovascular and neurological healthcare workflows, helping clinical teams explore patient information, monitor hospital operations, visualize anatomical structures, and review clinical information.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Internet connection for externally hosted libraries and fonts.
- A code editor such as Visual Studio Code.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/NEUROCARDIA-AI.git
```

### 2. Navigate to the project directory

```bash
cd NEUROCARDIA-AI
```

### 3. Run the application

Open the main HTML file in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
